# US-001 — RT 제어를 대기시키지 않는 동시 기록

- 관련 Intent: INT-001
- 관련 Milestone: 없음
- 상태: Approved — 2026-10-25 Human 「확정」으로 설계 기준선/AC 승인. 구현·검증 전
- 우선순위: Must(기능 방향 기준)
- 관련 요구사항: FR-001·002·007~009·012·013 / NFR-001·002
- 갱신: 2026-10-25 / AI

## 사용자 요구

로봇 애플리케이션 개발자는 여러 스레드에서 상태·수치·센서 데이터를 기록해도 제어 경로가 저장이나 공간 확보를 기다리지 않기를 원한다.

## 수락 기준 — 설계 기준선

- AC-1: 여러 생산자가 공통/개별 채널로 기록하고 목적별 파일에 분배할 수 있다.
- AC-2: 선언한 정상 부하에서 레코드 ID·내용을 대조해 설명되지 않는 손상·누락·중복이 없음을 확인한다.
- AC-3: 버퍼 포화·출력 장애에서 RT 호출은 공간/저장 완료를 기다리지 않고 수락 실패를 관측할 수 있다.
- AC-4: 무대기·중요 기록 우선·별도 보존 중요도의 기본값을 유지하고 일반 호출의 대기 옵션과 구분한다.
- AC-5: 호출 지연·처리량은 요구사항 §12의 검토할 기준 장비/부하와 함께 판정하며 실측 전에 달성으로 표시하지 않는다.

## 미정/검토 사항

요구사항 §12의 수치는 승인된 설계용 초기 기준선이며 실측 보장값은 아니다. 구체 장비·데이터 계약·실패 정책·API/제품·판정 오차는 OQ-002~005의 보완 계획에 따라 확정하며, 이 Story의 요구/AC 승인과 실제 구현 완료·성능 검증 통과를 구분한다.
