## 배경

TASK-024 S4 RSS 진단([EV-120](../../05_verification/verification_evidence.md#ev-120))에서 대표 부하(256 B 5,000건/s + 64 KiB 10건/s) 동안 전역 할당기 호출이 초당 약 13,100번 관측됐다. 살아 있는 heap은 평평해서 누수는 아니다. 다만 RT 제어 스레드의 기록 호출(`try_log`·loan)이 할당하는지, worker 쪽만 할당하는지 확인하지 않았다. 제어 스레드가 할당하면 NFR-001(RT 호출은 기다리지 않음)의 숨은 지연 원인이 될 수 있다.

## 작업 단계

| 단계 | 목표 | 종료 상태 | 상태 |
|---|---|---|---|
| S1 | 스레드별 할당 계측 | soak 카운팅 할당기에 스레드별(제어·프레임·worker·기타) 호출·바이트를 나눠 세고 짧은 실행으로 분포 확인 | Done — 300초 RT 실행: 제어·프레임 0, host 10,011/s, IO 3,158/s(EV-125) |
| S2 | 판정·조치 | 제어 스레드 할당 0이면 근거로 기록. 0이 아니면 위치를 찾아 제거 또는 사유 기록, 필요 시 회귀 시험(할당 0 단정) 추가. worker 쪽 할당은 빈도·크기를 기록하고 줄일 가치가 있으면 별도 제안 | Done — 제어 경로 0을 근거로 기록, soak `run`에 RT 스레드 heap 0 판정 추가(Red/Green). host·IO 감축은 지금 제안 안 함(재검토 조건 EV-125) |
