# ADR-011 — 현재 PC 실측·UPS 시뮬레이션 수락과 공개 후 native 검증

- 상태: Accepted / 날짜: 2026-10-31
- 승인: Human 「실제 UPS는 제공하지 못해서 시뮬레이션 테스트로 판정해야하고, 지금 이 PC는 우분투에 PREEMT RT 커널이 올라온 상태라, 이 PC로 검증한 결과로 실제 장치 테스트를 대신했으면해. native 검증은 github 프로젝트 공개 후, 진행 가능하고」
- 관련: INT-001 / MS-002~007 / TASK-004~011·021~024 / FR-018·NFR-001~003·007 / US-002 AC-7~9
- 관계: ADR-005·008·009의 실제 장비/UPS 시험 방법과 native 실행 시점만 이 결정으로 갱신한다. 기능·예산·오류/완료 계약·지원 OS·수치 목표는 유지한다. 이전 ADR 전체를 폐기하지 않는다.

## ADR 필요성 판단

- 비용: 실제 UPS/별도 장치 확보 제약에 맞춰 수락 시험을 변경한다.
- 운영 영향: 판정 가능한 증거의 범위와 native 검증 재개 시점을 장기간 바꾸므로 별도 ADR로 기록한다. 범위·방향은 Human이 이미 승인했다.

## 맥락과 결정 요인

구현·로컬 계약 시험과 Human 리뷰를 통과한 Task에도 native/장치 검증이 이월되어 있다. Human은 현재 개발 PC의 실측을 실제 장치 시험의 대체 근거로 수락하고, UPS는 실물을 제공하지 않으므로 시뮬레이션 결과로 판정하도록 결정했다. GitHub native 검증은 저장소 공개 이후 진행한다.

## 검토한 옵션

| 선택 | 결과 |
|---|---|
| 현재 PC 실측·UPS 시뮬레이션으로 수락, native는 공개 후 실행 | Human 선택. 별도 장비/UPS 확보 대기를 해소하며 관측한 환경과 시뮬레이션 범위를 명시한다. |
| 기존 실물 UPS·별도 장치·공개 전 native 필수 유지 | 제공/실행 여건과 맞지 않아 채택하지 않는다. |

## 결정

1. **현재 Ubuntu PC를 실제 장치 시험의 대체 수락 환경으로 확정한다.** CPU/메모리/디스크/파일 시스템·실행 커널·원본/출력 경로와 부하를 TASK-022에 고정한다. 이 PC에서 수행한 실제 파일 IO·동기화/복구·재생·지연/처리량/메모리/간섭 측정을 해당 프로필의 장치 시험 결과로 판정한다. 추가 센서·로봇/UPS 하드웨어 확보를 선행조건으로 요구하지 않는다. dot-probe 소프트웨어 통합 등 기존 구현 범위는 유지한다.
2. **UPS 수락은 시뮬레이션으로 대체한다.** TASK-021/024·TC-011의 실물 UPS/전원 차단 필수 절차를 모의 신호·전달 지연·차단 기한·중복/더 이른 기한·진행 IO·오류/부분 완료·중단/재개 후 복구/receipt 대조로 바꾼다. 전체 약3초는 모의 신호 원점부터 모의 차단 기한까지로 유지한다. 보고는 'UPS 시뮬레이션 합격(승인된 대체 판정)'으로 하며 물리 전원 차단/SSD 전원 소실 내구성의 관측 결과로 표시하지 않는다. 실물 UPS 제공을 열린 필수 입력으로 남기지 않는다.
3. **GitHub native 검증은 저장소 공개 완료 후 재개한다.** GAP-004는 승인된 이월로 Open/Not Run을 유지한다. 공개 전 구현·로컬 검증·준비를 진행할 수 있으며, 공개가 확인되면 AI가 당시 source hash를 고정해 6 contracts+audit+raw-memory를 실행/확인한다. 현재 visibility 변경·CI 조회/차단 재시도·계정/과금 조회를 수행하는 승인은 아니다. 공개 전 검토 T2와 공개 완료 후 검증 T3를 구분한다.
4. **RT 설치 이력과 실제 실행 커널을 구분한다.** 2026-10-31의 `7.0.0-38-realtime`/CONFIG_PREEMPT_RT=y 설치 관측은 과거 이력이다. **2026-11-02 Human 재확인: 현재 PC는 일반 Ubuntu 커널로 실행 중이며 RT 커널을 올려 실행한 상태가 아니다.** 같은 날 `uname -r`도 `7.0.0-42-generic`이다. RT 검증이 필요해지면 설치 상태를 재확인하고 필요한 설치·부팅 전환/재시작·시험 계획을 먼저 Human에게 요청한다. Human 승인 후 필요한 준비를 진행하며, 부팅 뒤 실제 실행 커널/CONFIG_PREEMPT_RT/sysfs/capability를 확인한 결과만 PREEMPT_RT 행에 기록한다. 현재 일반 커널 시험을 RT 결과로 승격하지 않는다.

## 결과와 검증 경계

- 환경 선택/수락 방식 승인과 시험 실행·합격은 별개다. 기존 로컬 Pass의 범위는 유지하고 새 실측·UPS 모의 시나리오는 실행 후 해당 EV로 판정한다. TASK-008/010 Human 리뷰 대기는 별도다.
- native 실행 시점은 승인된 이월이며 Pass/면제로 바꾸지 않는다. Task별 완료는 갱신된 완료 기준과 실행 근거로 개별 판단하고, 이번 정책 반영만으로 미실행 Task·Gate 4/5를 일괄 완료 처리하지 않는다.
- 24시간 시험·P0 대비 성능/자원·실제 시계 재생 측정과 소프트웨어 통합 요구는 유지한다. R1의 조건부 목표나 다른 OS 성능을 현재 PC 사양만으로 달성한 것으로 보지 않는다.
