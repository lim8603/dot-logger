# US-003 — 기록 데이터의 조회·재생과 외부 활용

- 관련 Intent: INT-001
- 관련 Milestone: 없음
- 상태: Approved — 2026-10-25 Human 「확정」으로 설계 기준선/AC 승인. 구현·검증 전
- 우선순위: Must(기능 방향 기준)
- 관련 요구사항: FR-004~006·010 / NFR-002
- 갱신: 2026-10-25 / AI

## 사용자 요구

분석 및 모니터링 개발자는 수집한 데이터를 시간에 따라 조회·재생하고 선택한 DB/클라이언트에서 활용하기를 원한다.

## 수락 기준 — 설계 기준선

- AC-1: 첫 dot-probe 적용은 자체 기록·조회·재생이며 ROS 2 호환은 적용 완료 후 T1로 검토한다.
- AC-2: 조회·재생·DB/모니터링 경로의 완료 경계와 동시 수집 영향이 문서화돼 있다.
- AC-3: 소형 수치·이벤트와 큰 원본을 목적에 맞게 전달하고 모든 원본의 시계열 DB 저장을 기본 가정하지 않는다.
- AC-4: 클라이언트 형태·DB 제품·프로토콜은 설계에서 비교/선정하며 미측정 경로의 성능을 보장했다고 표시하지 않는다.
- AC-5: 지연·조회 응답·원격 처리량은 요구사항 §12의 초기 목표와 실제 장비/부하 조건을 함께 검증한다.

## 미정/검토 사항

요구사항 §12의 수치는 승인된 설계용 초기 기준선이며 실측 보장값은 아니다. 구체 장비·데이터 계약·실패 정책·API/제품·판정 오차는 OQ-002~005의 보완 계획에 따라 확정하며, 이 Story의 요구/AC 승인과 실제 구현 완료·성능 검증 통과를 구분한다.
