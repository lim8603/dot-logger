## 평가 근거

2026-10-25 초기 조사에 따른 예비 정성 평가다. 발생 확률·영향도는 실측 수치가 아니다. 조사 자료(비공개 원시 근거)와 [요구사항의 미결 항목](requirement_spec.md)을 기준으로 후속 답변에 맞춰 갱신한다.

## 2026-10-26 상세 대응 연결

기존 리스크는 아직 Open이다. RSK-001/004는 TASK-003·004의 RT 전체 호출·최종 해제·반납 포화·앱 thread 수명 검증, RSK-002/005는 TASK-008·009·021·024의 파일/긴급 예산·실제 차단, RSK-003은 TASK-005·012·023의 fanout/복사/부하, RSK-006은 TASK-014~017·023의 관측 정합성/오차/비용, RSK-007은 TASK-002·022·024의 native OS·교환 검증으로 연결했다. MCAP 인덱스 메모리·active reader, DB timestamp 충돌은 각각 TASK-007·010·019에서 확인한다.

## 2026-10-31 수락 범위 갱신

[ADR-011](../03_design_artifacts/adrs/ADR-011_local_pc_simulated_ups_verification.md)으로 RSK-001/002/005의 장치 수락은 현재 PC 실측/UPS 시뮬레이션으로 판정한다. 물리 전원 소실 시 SSD/컨트롤러의 보존 특성은 직접 관측하지 않는 범위로 명시하며 실물 UPS 제공을 미결 필수 입력으로 요구하지 않는다. RSK-007 native/OS 교환은 공개 완료 후 수행한다. 승인된 시험 대체/이월과 실행된 Pass를 구분하며 기존 리스크 등급·제품 기능 계약은 유지한다.

TASK-014 후속(2026-10-31): RSK-006은 계속 Open이다. 로컬 counter/history·누락/reset·정합성 검증 및 overhead fixture 준비는 기본 계측 완료 처리량 비용≤5%·장기 추정 오차/RT 수락과 별도다. TASK-022/023의 조건을 고정한 실측과 TASK-015~017의 분모/추정/비교 검증을 수행한다.
