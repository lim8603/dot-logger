# US-005 — Linux·macOS·Windows의 공통 기능과 기록 교환

- 관련 Intent: INT-001
- 관련 Milestone: MS-002·003·004·007 (계획 승인)
- 상태: Approved — Human의 크로스 플랫폼 지원 지시 기준. 세부 매트릭스/검증은 Design에서 정의
- 우선순위: Must
- 관련 요구사항: NFR-007·CON-002, FR-001~014·016·017
- 근거: ADR-006 / 2026-10-25

## 사용자 요구

개발자는 Linux·macOS·Windows에서 같은 로깅 라이브러리와 클라이언트의 핵심 기능을 사용하고 OS 간 기록을 읽으며 플랫폼별 부하·지원 기능을 확인하기를 원한다.

## 수락 기준

- AC-1: 라이브러리/클라이언트의 공통 수집·기록·조회/재생·관측/점검·개발자 조절 경로를 세 OS에서 제공한다.
- AC-2: 선언한 OS/아키텍처 매트릭스에서 실제 빌드·실행·핵심 기능을 검증하고 크로스 컴파일만으로 실행 지원을 판정하지 않는다.
- AC-3: 공통 기록을 OS 간 읽고 시각/순서·스키마·무결성 의미를 유지하며 회전·재열기·종료·복구를 검증한다.
- AC-4: OS 전용 최적화/계측의 미지원·권한 부족을 표시하고 공통 기능을 Linux 전용 지표에 의존시키지 않는다.
- AC-5: Linux PREEMPT_RT의 R1 초기 수치와 다른 OS의 실제 프로필을 구분하며 모든 OS의 동일 지연 보장을 검증 없이 주장하지 않는다.

## 미정/검증 조건

최소 OS 버전·CPU 아키텍처·MSRV·선정 의존성·CI/네이티브 실행 환경·플랫폼별 성능·예외 기능 매트릭스를 Design에서 정한다. 코드/테스트 실행 전이므로 이 요구의 승인과 검증 완료는 구분한다.
