# ADR-006 — Linux·macOS·Windows의 크로스 플랫폼 지원

## 상태·날짜

`Accepted` · 2026-10-25 · 결정자: Human

대체: [ADR-001](ADR-001_rust_linux_preempt_rt.md). Rust 재사용 라이브러리·첫 적용 dot-probe·실시간 목표는 계승하고 OS 지원 범위를 확장한다. ADR-003·004·005는 유지한다.

## 근거와 결정 이유

Human이 「요구사항에서 중요한 하나가 빠졌다. 크로스 플랫폼. 리눅스, 맥, 윈도우 지원」이라고 명시했다. OS 지원은 공통 API·의존성·파일/동기화·스레드·계측·배포/검증에 장기 영향을 주므로 ADR로 확정한다.

## 결정

1. Rust 로깅·텔레메트리 라이브러리와 모니터링/조회 클라이언트의 지원 OS는 **Linux·macOS·Windows**다. 서버 라이브러리는 Linux에만, 클라이언트만 나머지 OS에 제공하는 범위로 축소하지 않는다.
2. Linux의 일반 사용과 Linux + PREEMPT_RT의 실시간 최적화/검증을 포함한다. 기존 RT 무대기 API 계약은 유지한다. OS 지원 승인이 모든 OS/장비에서 같은 지연·처리량이나 같은 실시간 보장을 이미 검증했다는 뜻은 아니다.
3. 공통 수집·기록·파일 운영·조회/재생·리포트·점검/개발자 조절 기능을 세 OS에서 제공하도록 설계한다. OS별 시각·스레드/실시간 설정·파일/동기화·자원 관측은 공통 계약 아래 분리한다.
4. 플랫폼별로 제공할 수 없는 고급 계측/최적화는 기능/권한 지원 여부를 명시한다. 미지원 지표를0이나 정상 여유로 표시하지 않고 공통 기능을 특정 OS 계측에 종속시키지 않는다.
5. 같은 기록의 OS 간 읽기/교환과 파일 회전·종료·완료 의미를 검증한다. 실제 OS 버전·CPU 아키텍처·MSRV·CI 실행 환경·네이티브 테스트 범위는 Design에서 구체화한다. 크로스 컴파일만으로 실행 호환을 검증했다고 보지 않는다.
6. ADR-005의 R1/P0~P6·초기 수치·2 GiB 기준 버퍼는 Linux + PREEMPT_RT 참조 프로필로 유지한다. macOS/Windows의 실제 성능/계측 기준은 해당 장비·OS 프로필로 평가하며 자동으로 R1과 동일시하지 않는다.

## 영향과 미결

Linux 전용 기능/의존성의 공통 경로 노출, 파일/동기화/스레드/시각/자원 지표 의미 차이를 설계/검증해야 한다. Linux 전용 계측을 macOS/Windows에 그대로 요구하지 않는다. SDK 언어, GUI, DB/형식/큐/런타임 선정은 이번 OS 지원 지시로 확정하지 않는다. 실제 빌드/네이티브 실행/성능 검증은 아직 수행하지 않았다.
