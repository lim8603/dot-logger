# ADR-008 — 제한된 소유권·예약·완료와 실패 계약

- 상태: Accepted / 날짜: 2026-10-26 / 승인: 2026-10-26 Human 「권고 기준선 채택 — 장비·호환 검증은 계획대로 진행」
- 관련: INT-001 / MS-001~003·005·006 / US-001·002·004 / ADR-003~007
- 권한: 오류·허용 손실·공개 수명 제약·운영 기본값이 결합된 J 결정으로 Human 승인 완료.

## 맥락과 선택

RT 무대기와 유한 메모리를 지키면서 모든 장애에 무손실을 보장할 수 없다. 기존 정책 기본값을 유지하고 실패·회수·완료를 관측 가능한 계약으로 좁힌다.

| 쟁점 | 권고 | 검토한 대안/비용 |
|---|---|---|
| RT 원본 수명 | session owner + borrowed producer/loan, 슬롯별 반납 상태, 회수는 background | Arc 마지막 Drop은 RT free 가능. 외부 SDK buffer 직접 전달은 callback/수명 추가 검증 필요 |
| 중요도 | Normal/Important, 명시값 → 채널 정책 → Normal | 다단계는 예약/공정성 조합 증가, 실제 필요 때 확장 |
| 예약·포화 | producer별 slots/bytes quota, Important 예약, 포화 시 신규 거절 | 기존 수락 레코드 축출은 참조/완료 처리 복잡. global CAS 예산은 경합 상한 검증 추가 |
| 순서 | producer별 FIFO·수락 sequence, 전역 순서 없음 | 전역 정렬은 늦은 생산자 대기/메모리 증가 |
| 수락과 fanout | 수집/완료 추적 예산만 원자 인수, 출력별 결과 독립 | 모든 출력 공간 사전 확보는 RT 비용·대상 간 결합 증가 |
| 완료 | 대상별 written/synced/DB API ack/receiver ack·실패/폐기/불명/만료 | 단일 성공 bool은 부분 완료와 손실을 숨김 |
| 변경 | 필터·샘플링·기존 대상 route만 런타임 변경, per-producer 적용 ack | 전역 원자 설정 교체는 정지/추가 동기화 비용 |
| 종료 | deadline 때 incomplete와 owner 유지, 사용 중 메모리 강제 해제 금지 | 즉시 detach/drop은 수명/누수 위험 |
| 파일 기본값 | 명시 quota/보존 모드, 압축 off·CRC/index on을 첫 시험값으로 사용 | 장비 미확정 상태에서 용량·손실 기본값을 확정하지 않음 |
| 긴급 종료 | 기본 off 유지, rank→target ID 순서, 새 일반 입력 닫기·별도 snapshot 예약, 가장 이른 deadline | 신호마다 3초 재설정·즉시 IO 취소 가정은 잘못된 시간 보장 |

## 상세와 합격 조건

[도메인 §3~5](../domain_model.md), [인터페이스 §13~17](../interface_contract.md), [데이터 §3~6](../data_model.md) 참조. TC-002·003·005·009~011로 경계/실패를 확인한다. US-002 AC-6~10과 계측 예산(기본 계측 처리량 비용 ≤5%, 안정 추세 예측 오차 ≤20%)은 이번에 승인된 **설계 기준선 수락 조건**이다.

2 GiB 배분표는 R1 시험용 구성이지 제품 기본값이 아니다. 512 MiB/4 GiB 비교, 장비별 디스크·UPS 보호량은 유지한다. 실제 지연·복구·무할당 달성은 구현/장비 검증 후 판정한다.

## 결과

실패를 명시하고 RT 비용/메모리 상한을 설명할 수 있다. producer별 quota는 유휴 공간 공유 효율을 낮추며 borrowed API는 앱 thread 수명 구조에 제약을 준다. TASK-004에서 dot-probe 통합의 수명 적합성을 먼저 검증하고 성립하지 않으면 이 ADR을 재검토한다.

## 승인 범위

상세설계·기술 선택·추가 시험 목표·MS 계획의 기준선 채택을 승인받았다. 장비별 수락 조건·의존성/MSRV 호환 확인은 TASK-002·022에 남긴다. FR-015/TASK-018은 별도 제안이다. 실제 구현·성능·제품 테스트 통과를 승인한 것은 아니다.
